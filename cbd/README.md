# 花城漫步 · 珠江新城（二次元 3D 城市漫游）

第一人称在广州珠江新城的花城广场一带走、跑、飞行观光。画风参考《无限大》玩法预告里的城市：结构干净写实，天空手绘，颜色高饱和、冷暖分明。

## 运行

在仓库根目录 `node server.js`，然后打开 http://localhost:5199/cbd/ 。

- 鼠标转视角（锁不住鼠标时按住拖动，或用方向键），`WASD` 走，`Shift` 跑，空格跳
- `F` 飞行观光（`Q`/`E` 升降，`Shift` 加速），`H` 隐藏界面
- 手机：左半屏摇杆、右半屏拖动转视角，右下角按钮跑/跳/飞行（只在桌面模拟里看过）

## 场地

x 向东、z 向南，尺寸在 `src/layout.js`。中轴是花城广场（步道、草坪、花带、中心湖和喷泉），两侧是珠江西路 / 珠江东路，北端花城大道，南端临江大道和珠江。

地标：西塔（圆角三角形平面 + 斜交网格）、东塔（方塔逐级收分）、广州图书馆、广东省博物馆、第二少年宫、广州大剧院、珠江城、中信广场（中轴北端远景）、海心沙、广州塔（江对岸）。

## 画面怎么做出来的

- **天空**：一张 Codex 出的手绘云图，水平镜像铺满 360°（`src/sky.js`）；玻璃幕墙和水面的反射采样同一张图，所以楼上能看到云。
- **幕墙**：一个着色器配十来种样式（`src/mats.js` 的 `STYLES`）：窗格、竖向遮阳板、横向窗带、斜交网格都按“米”画，线条做了面积滤波，远看不闪。
- **地面**：整块地面一个着色器，按坐标解析地画出铺装、草坪、花带、车道标线、斑马线、盲道、路缘石，再叠一层缓慢飘过的云影。
- **树**：绒球树 = 一堆永远朝向相机的叶簇面片，法线取球面方向，三段式卡通明暗（`foliageMat`）；椰树是弯折的叶片面片。
- **光**：太阳放在北偏西的高处，花城广场不被塔楼影子盖住；阴影偏蓝，雾随高度变淡，远楼自然分层。
- **后期**：泛光 → 柔肩曲线、提饱和、镜头光晕（太阳被楼挡住时自动收掉）。

- **去塑料感**：光比拉开（强而暖的太阳、弱而蓝的环境光）、环境光遮蔽、玻璃按朝阳/背阳分明暗；幕墙、石材立面、沥青、人行道砖用 Codex 的手绘贴图。
- **近景建模**（`src/street.js`）：店面是真开间（壁柱、招牌盒、雨棚、玻璃、退进去的室内），西塔外面是真的斜交钢管，东塔下段是真的竖向陶板，另有柱廊、过街天桥、路中护栏花箱、路灯、共享单车、垃圾桶、挤出轮廓的汽车和公交。

## 素材

`tools/prompts.json` 写提示词 → `tools/gen.ps1 -Names a,b` 调 Codex 出图到 `assets/gen/` → 把选中的图复制到 `assets/src/<名>.png` → 在本地页面控制台里跑 `tools/bake.js` 压成 `assets/web/*.webp`（入库的只有 webp）。
