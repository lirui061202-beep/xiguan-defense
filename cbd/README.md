# 花城漫步 · 珠江新城（二次元 3D 城市漫游）

第一人称在广州珠江新城的花城广场一带走、跑、飞行观光。画风参考《无限大》的城市：场景是“风格化写实”——深色低饱和玻璃映着天、白色构件、空气透视重、屋顶堆满设备，彩色只留给招牌。

## 运行

在仓库根目录 `node server.js`，然后打开 http://localhost:5199/cbd/ 。线上直接跑源码，没有打包。

- 鼠标转视角（锁不住鼠标时按住拖动，或用方向键；双击画面再尝试锁鼠标），`WASD` 走，`Shift` 跑，空格跳
- `F` 飞行观光（`Q`/`E` 升降，`Shift` 加速），`H` 隐藏界面
- 手机：左半屏摇杆、右半屏拖动转视角，右下角按钮跑/跳/飞行（只在桌面模拟里看过，没做降档）

场地：中轴是花城广场（步道、草坪、花带、中心湖、栈桥、喷泉），两侧珠江西路 / 珠江东路，北端花城大道，南端临江大道和珠江。地标：西塔、东塔、广州图书馆、广东省博物馆、第二少年宫、广州大剧院、珠江城、海心沙、广州塔。

## 画面怎么做出来的

- **天空**：一张 Codex 出的云图，水平镜像铺满 360°，采样时略微模糊让云边变柔；玻璃和水面的反射采样同一张图。
- **幕墙**：一个着色器配十来种样式（`STYLES`），窗格、竖肋、横带、斜交网格都按“米”画，线条做面积滤波。玻璃 = 暗的本体 + 清楚的天空反射，按朝阳 / 背阳分明暗；近看有室内视差（每三格玻璃一个房间）。
- **地面**：整块地面一个着色器，按坐标画出铺装、草坪、花带、标线、斑马线、盲道、路缘石、井盖和云影，掠射角映天空。
- **近景一律建模**：店面是真开间（壁柱、门、橱窗、室内、灯箱招牌、挑牌、幌子），楼面是真凹窗（墙垛、窗台、腰线、空调外机、阳台），另有骑楼、转角塔楼、挑檐、天桥、护栏、路灯、单车、售货机、报刊亭等。贴图只用在远处和画面类的东西上（海报、售货机面板、菜单）。
- **植被**：树冠、绿篱、花丛是朝向相机的叶簇面片，法线取球面方向；椰树叶是真几何（一根叶轴加两排小叶片）。
- **光和雾**：太阳在南偏东，商场临街店面受光；强而暖的太阳配弱而蓝的环境光；雾随高度变淡，远楼泛白分层。
- **后期**：环境光遮蔽 → 泛光 → 轻微锐化、柔肩曲线、略降饱和、镜头光晕。

## 素材

`tools/prompts.json` 写提示词 → `tools/gen.ps1 -Names a,b` 调 Codex 出图到 `assets/gen/` → 把选中的图复制到 `assets/src/<名>.png` → 在本地页面控制台里跑 `tools/bake.js` 压成 `assets/web/*.webp`。

仓库和本机都只留了最终的 WebP；`assets/gen/`、`assets/src/` 的原图已清理，要重新出图按上面的流程再走一遍即可。
